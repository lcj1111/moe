## 四、发布前检查

仓库发布收尾必须满足：

- 分支为 `agent/sync-q-topomoe-project`，工作区干净；
- release manifest 中所有仓库文件 SHA-256 与实际文件一致；
- JSON、配置、Markdown 链接和 Phase 8 单元测试通过；
- 正式标签指向包含本清单和 release manifest 的提交；
- 历史失败、无效尝试和当前 accepted 结果保持分离。

模型权重体积较大，不存入 Git。正式生产部署前必须在目标主机生成模型目录逐文件 manifest，
至少记录相对路径、字节数和 SHA-256，并与部署审批单绑定。模型目录内容哈希缺失时不得切换
生产流量。

## 五、生产部署阶段需要完成的工作

生产部署是新的运维变更，不再修改 Phase 8 的实验结论或 Gate。

### 1. 变更准备

1. 明确服务负责人、监控负责人、回滚负责人和维护窗口。
2. 从正式 release tag 创建部署包，不从未提交工作区部署。
3. 在目标主机核对 GPU 数量、P2P/NCCL、驱动、CUDA、vLLM 版本和运行时补丁哈希。
4. 生成模型目录完整哈希 manifest，并核对 placement 文件、map 和补丁哈希。
5. 预留 identity map、上一稳定服务配置和一键流量回切入口。

### 2. 部署前基线

先以 identity placement 启动隔离实例，记录健康状态、请求失败率、吞吐、p50/p95/p99、
GPU 显存和错误日志。基线请求协议应与正式 canary 一致，不能用冷启动窗口作为比较基线。

### 3. 小流量发布

1. 初始只接入一个隔离副本或约 5% 流量。
2. 稳定窗口完成后显式激活暖态 placement，不允许启动时静默替换。
3. 核验 8/8 rank 提交相同 map 哈希，generation 只递增一次。
4. 检查请求失败、输出完整性、延迟、路由稳定性和决策开销。
5. 小流量 accepted 后，才按 `5% → 25% → 50% → 100%` 分级扩容；每一级单独记录开始、结束、指标和决策。

### 4. 建议生产准入条件

- 请求失败数为 0；
- 8-rank map 哈希完全一致；
- 恢复或稳定后 p99 不超过同级 identity 基线的 105%；
- placement excess TV p95 不超过当前 1%；
- 决策开销 p95 小于 1%；
- 不可行配置误选率为 0；
- 质量 smoke 零失败、零截断，且没有新增确定性退化；
- trigger、cooldown 和 rollback 状态机没有越级或重复提交。

### 5. 自动闭环启用顺序

先以只观测模式确认指标输入正常，再启用 trigger；确认一次 generation=1 placement apply 后，
完整观察 10 个 cooldown 窗口。只有 cooldown 正常，才允许自动 rollback 保持启用。不得同时修改
阈值、placement map 和流量比例，否则无法归因。

### 6. 立即回滚条件

出现以下任一情况，停止扩量并回到 identity placement；必要时将流量切回上一稳定实例：

- 任一请求失败、进程退出、CUDA/NCCL 错误或 rank 失联；
- 8-rank map 哈希不一致、重复 apply 或 generation 异常；
- p99 连续三个合格窗口超过冻结基线 105%；
- 路由稳定性超过 1%、出现不可行配置误选或确定性质量退化；
- rollback 未能在三窗口条件满足后提交，或回滚后状态未恢复为 identity。

回滚后保留日志、控制器状态、map 哈希、请求摘要和时间线，不覆盖失败现场。

### 7. 生产验收与归档

生产发布完成后生成单独的生产部署 manifest 和中文报告，至少记录目标主机、release tag、
模型 manifest、流量阶梯、每级指标、触发/回滚事件和最终状态。只有生产 Gate accepted，才能
把项目状态从“技术验收完成”改为“已生产部署”。

## 六、不应继续做的工作

- 不再反复调整当前 12% 和 1% 政策以追逐单次测量；
- 不再用已揭晓的 900 次独立结果重新训练冻结 selector；
- 不把历史无效尝试合并进正式 accepted 结果；
- 不在生产变更中顺带修改模型、placement、控制器和流量策略；
- 不把本次技术 release tag 描述为生产发布标签。

## 七、当前边界

完成本发布标签后，Q-TopoMoE 实验项目可以结项。若用户决定实际承接生产流量，则从本清单
第五节启动一个独立的生产部署任务；SGLang 不属于本发布范围。
