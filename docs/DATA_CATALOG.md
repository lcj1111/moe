# Q-TopoMoE data and artifact catalog

This catalog documents every tracked machine-readable artifact under `configs/`, `docs/`, or `data/`. It is intentionally one file instead of one README per artifact, so the repository stays compact without hiding provenance.

## How to read the entries

- **Frozen input / manifest**: consumed by a reproduction or evaluation command; do not edit in place. The path and SHA-256 together pin the input.
- **Experiment plan**: executable or semi-executable control data; preserve the path because scripts and runbooks may reference it.
- **Evidence / result**: a recorded measurement, audit, gate, or summary. It is not a runtime input unless a manifest explicitly points to it.
- **Archive evidence**: historical comparison only; it is retained for auditability and must not be used as a current gate.
- Raw benchmark payloads are intentionally not tracked; manifests record their expected locations and hashes when needed.

Data filenames retain dates and versions because those are provenance, not clutter. Human-readable semantic groupings are provided by `docs/results/phase*.md`; no machine-readable path was renamed or removed.
